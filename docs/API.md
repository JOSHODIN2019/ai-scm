# API Reference

Base URL (local dev): `http://localhost:8001`

All endpoints except `/api/auth/register` and `/api/auth/login` require
`Authorization: Bearer <token>`. Errors follow FastAPI's standard shape:
`{"detail": "message"}` or, for validation errors, `{"detail": [{"msg": "..."}]}`.

## Auth

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/register` | Create an account, returns token + user |
| POST | `/api/auth/login` | Log in, returns token + user |
| GET | `/api/auth/me` | Current user (requires auth) |

## Projects

| Method | Path | Description |
|---|---|---|
| GET | `/api/projects` | List the current user's projects |
| POST | `/api/projects` | Create a project |
| GET | `/api/projects/{project_id}` | Get one project (must be owner) |
| PATCH | `/api/projects/{project_id}` | Update a project |
| DELETE | `/api/projects/{project_id}` | Delete a project and its changes |

## Software changes

| Method | Path | Description |
|---|---|---|
| GET | `/api/projects/{project_id}/changes` | List changes for a project |
| POST | `/api/projects/{project_id}/changes` | Record a software change |
| GET | `/api/changes/{change_id}` | Get one change |

## AI analysis

| Method | Path | Description |
|---|---|---|
| POST | `/api/changes/{change_id}/analyze` | Run AI analysis, persist and return the result |
| GET | `/api/changes/{change_id}/analyses` | List analysis results for a change (newest first) |

Response includes `is_mock: boolean` — `true` whenever the heuristic mock
analyzer produced the result rather than a real OpenAI call. The frontend
surfaces this directly next to the result, per PROJECT_MEMORY.md's rule
that mock output must never be presented as a real model result.

## GitHub integration

| Method | Path | Description |
|---|---|---|
| GET | `/api/projects/{project_id}/github/commits?page=N` | Paginated commit history (20/page) for the project's `repository_url`. Returns `422` if the URL isn't a valid `https://github.com/<owner>/<repo>` form, `400` if the project has no `repository_url`, `404` if the repo doesn't exist, `429` if GitHub's rate limit is hit. |
| POST | `/api/projects/{project_id}/changes/import-github` | Body: `{"commit_sha": "..."}`. Fetches the commit + diff from GitHub and creates a `software_changes` document — or returns the existing one if that SHA was already imported for this project (no duplicates). The resulting change is a normal software change; `POST /api/changes/{id}/analyze` works on it exactly as it does on manually-entered changes. |

Public repositories work unauthenticated (GitHub's 60 req/hr limit). Set
`GITHUB_TOKEN` in `backend/.env` to raise that ceiling or access private
repos — never sent to the frontend.

## Evaluation
